#  Hospital Readmission and Patient Outcome Analysis

An interactive Power BI dashboard analyzing hospital admissions, 30-day readmission rates, patient outcomes, treatment costs, and length of stay to support data-driven healthcare decisions.



##  Project Overview

This project explores hospital admission data to identify trends in patient readmissions, treatment costs, and clinical outcomes. Using Power BI, an interactive dashboard was developed to help hospital management monitor key performance indicators and identify areas requiring operational improvement.


##  Objectives

- Monitor 30-day readmission trends
- Identify high-risk departments and patient groups
- Analyze treatment costs and patient outcomes
- Support data-driven decision-making through interactive dashboards


##  Tools Used

- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Power BI

##  Key Insights

- October recorded the highest 30-day readmission rate.
- Cardiology had the highest departmental readmission rate.
- Patients aged **61 years and above** recorded the highest readmission rate.
- Higher treatment costs did not consistently lead to better patient outcomes.
- ICU, Oncology, and Cardiology combined high treatment costs with relatively high readmission rates.



##  Recommendations

- Improve discharge planning in high-readmission departments.
- Strengthen post-discharge follow-up for elderly patients.
- Investigate factors contributing to seasonal readmission spikes.
- Monitor treatment costs alongside patient outcomes to improve resource utilization.
